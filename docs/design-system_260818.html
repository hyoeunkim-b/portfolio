04

Editorial primitives

박스보다 여백, 정렬, 활자 위계와 얇은 선으로 관계를 만든다. 같은 모양이 아니라 같은 의미가 반복될 때 재사용한다.

관찰 · Observe

익숙한 것에서 놓치기 쉬운 신호와 맥락을 찾는다.

연결 · Connect

흩어진 정보와 사람, 관점 사이에 실제로 존재하는 관계를 드러낸다.

구조화 · Structure

복잡성을 읽을 수 있는 질서와 이야기, 시스템으로 편집한다.

정제 · Make useful

핵심을 남기고 누군가 실제로 사용할 수 있는 결과로 완성한다.

07

System rules

01

Typography carries the identity

장식보다 크기, 행 길이, 굵기, 정렬과 줄바꿈으로 목소리를 만든다.

02

Grid creates order; exceptions create energy

기본은 엄격하게 정렬하고 핵심 요소만 의도적으로 열을 넘긴다.

03

Rules before boxes

카드, radius, shadow보다 공간과 얇은 rule을 먼저 사용한다.

04

Responsive means recomposition

모바일은 데스크톱의 축소판이 아니라 읽는 순서와 밀도를 다시 편집한 화면이다.

05

Accessibility is a visual state

명료한 구조, 대비, focus, 의미론과 reduced motion을 기본 품질로 다룬다.
