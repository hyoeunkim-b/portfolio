- 스크롤 영역에 키보드 초점과 설명을 제공한다. 도식의 각 기능에는 화면 너비와 관계없이 웹·메타버스 역할을 읽을 수 있는 레이블을 둔다.

- 랜딩의 스크롤은 MP4에 인코딩된 움직임이다. 방문자의 입력이나 본문 사용자 화면의 자동 스크롤과 무관하다.
- 관리자 이미지는 본문의 `admin-list`, `admin-new`, `admin-date`를 활용한다. 화면 너비에 맞춘 이미지 높이가 1080px 화면의 2배 이상이면 상단→하단 스크롤 영상으로 만든다.

- `kit-preview-scenes.json`에서 영상 생성의 장면 순서와 시간을 관리한다.
- 재생성: `FFMPEG_BIN=/path/to/ffmpeg python3 scripts/build-kit-preview.py`. FFmpeg와 로컬 원본이 필요하며, 임시 세그먼트는 생성 후 정리한다.

- 변경본은 약 11.4MiB이며 린트·타입 검사·정적 빌드를 통과했다. 0·7·13초 랜딩 화면과 17·22·26초 강의 등록 화면을 추출해 상단→중간→하단 이동을 확인했다.
