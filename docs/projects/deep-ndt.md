## 반응형과 검수

- NDT 전용 CSS에서만 파란 강조색, 회색 배경, 지표 카드와 인용문 형태를 적용한다. 글로벌 브랜드 토큰은 변경하지 않는다.
- 1200px 이상에서는 왼쪽 섹션 라벨과 오른쪽 본문, 가로 흐름도를 사용한다.
- 작은 화면에서는 라벨과 본문을 순서대로 쌓고 흐름도를 세로로 재구성한다. AI 화면 내 주석은 모바일에서 별도 텍스트로 제공한다.
- 1440, 768, 390, 320px Chrome 검수에서 이미지 누락 및 문서 가로 넘침이 없음을 확인했다.
- 린트, TypeScript 검사와 정적 빌드가 통과했다.

## 모바일 AI 기능 확대 — 2026-09-19

- 수정된 Figma `476:2637` 시안을 기준으로 전체 화면과 확대 슬라이드 3개를 구성했다. 사용자가 제공한 `case-2-all.png`, `case-2-1.png`~`case-2-3.png`를 그대로 사용한다.
- 전체 화면 아래 우측 캡션, 80px 뒤 가로 슬라이드를 배치한다. 확대 화면은 302:280 비율, 이미지와 설명 사이 24px, 제목 19px, 본문 15px이며 코드에서는 rem을 사용한다. 세 슬라이드 모두 첫 슬라이드의 번호·제목 패턴을 적용한다.
- 스크롤 영역은 전체 폭이고 처음과 끝에 24px 여백을 둔다. 슬라이드 간격은 수정 시안의 40px이며, 점 버튼과 가로 스크롤 모두 현재 위치를 반영한다.
- 390px·320px 모바일에서 이미지 로딩, 마지막 슬라이드 선택, 가로 넘침을 확인했고, 1440px에서 기존 데스크톱 주석 이미지가 표시되는 것을 확인했다.

- 모바일 AI 슬라이드 영역 다음 보고서 연결 내용까지 간격은 5rem(80px)이다. 보고서 제목과 설명은 4열·20px 갭 기준 우측 3열에 정렬한다. 보고서 이미지는 전체 콘텐츠 너비를 유지한다.

- 모바일 사례 2 결과 카드도 사례 1과 같이 2열씩 한 행에 배치한다. 카드 간격 1.25rem, 내부 패딩 1.5rem 1rem, 제목 .9375rem, 괄호 설명 .8125rem, 강조 수치 1.6875rem을 사용한다. 제목은 한 줄로 유지하고 수치의 하단 위치를 맞췄다. 390px·320px에서 정렬과 넘침을 확인했다.

- 모바일 최종 결과 흐름 카드 3개는 제목 1.1875rem(19px), 설명 .9375rem(15px)을 사용한다.

- 모바일 회고의 세 항목은 제목, 설명과 구분선 전체를 4열·20px 갭 기준 우측 3열에 정렬한다.
