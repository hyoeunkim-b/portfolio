## 레이아웃

- 기존 상세 페이지의 Header, Overview, 섹션 제목, 이전·다음 탐색, Contact를 공유한다.
- 히어로는 높이 400px, 데스크톱 제목은 35px를 기준으로 한다.
- 데스크톱 본문 이미지는 오른쪽 9열에 배치한다. 섹션 위아래 160px, 작업 묶음 간 120px, 이미지 간 40px는 Figma 값이다.
- 검은 둥근 작업명 라벨은 시안의 표현을 적용한 이 상세 페이지의 예외다.
- 회사소개서는 2열, 상품소개서와 슬라이드는 대표 이미지 1장 후 2열, 매뉴얼과 보고서는 3열로 구성한다. 제품소개서는 표지와 내지 비율을 다르게 두고 아래를 맞춘다.
- 모바일(768px 미만)은 각 갤러리를 좌우 스와이프 슬라이드로 재구성한다. 슬라이드 영역은 화면 양끝까지 확장하고 첫 이미지 앞과 마지막 이미지 뒤에만 페이지 여백을 둔다. 다음 이미지 일부가 보이며, 하단 원형 버튼으로 이미지 수와 현재 위치를 표시하고 직접 이동할 수 있다. 이미지가 한 장인 갤러리는 표시를 생략한다. 모든 본문 이미지는 선택하면 원본 크기로 확대할 수 있으며, 확대창 안에서 스크롤한다. 닫기 버튼과 Escape를 지원하고 닫은 뒤 선택 이미지로 초점을 돌려준다.
