# VARLOS Web VR Editor — 상세 페이지

2026-09-23 · 최종 Figma 기반 웹 구현 / 사용자 모바일 검토 대기

## 기준과 범위

- [최종 Figma project-detail-design](https://www.figma.com/design/7ONQ4V6pBqJAPEtnoH2b8h/2406_WebVR?node-id=10-119), 1440px 시안 기준.
- 요약 → 상황 → 1차 개선 → 2차 개선 방향 → 개선 3개 → 결과 → 회고 순서와 최종 문구를 반영했다.
- 공통 Header, 이전/다음 프로젝트, Contact는 유지했다. 상세 히어로와 프로젝트 본문만 구현했다.
- URL은 기존 `/projects/valros/`를 유지하며 화면의 제품명은 최종 Figma의 VARLOS를 따른다.
- 전체 개발 약 6개월, 본인 작업은 1차 1주·2차 2주. 두 버전의 디자인과 퍼블리싱을 담당하고 개발자 1명과 협업했다.
- 결과의 사용성 평가는 사내·고객의 정성적 피드백이다. 튜토리얼은 프로토타입 단계의 피드백이며 운영 환경의 정량 검증으로 표현하지 않는다.

## 자산과 목업

- 사용자 제공 `public/images/projects/valros/`의 WebP 자산을 사용했다. 이미 잘린 화면 자산에는 Figma의 원본 이미지 크롭을 중복 적용하지 않는다.
- 상세 히어로는 `cover_hero.webp`, 홈·목록 썸네일은 `cover_small.webp`다. 모바일(48rem 미만)에서는 `object-position: right center`로 VR 장비가 보이도록 우측 정렬한다.
- `gif-sources/gif01.png`부터 `gif19.png`까지 순서대로 `scripts/build-valros-gif.py`로 GIF를 생성한다.
- 원본 1920×944 비율을 유지한 1440×708 GIF, 19프레임, 38초 반복, 약 5.08MB. 일반 화면 1.8초, 튜토리얼 2.4초, 마지막 화면 2.6초.
- 노트북 목업은 CSS에서 1653:878 비율로 표시하여 내부 화면과 GIF 비율을 맞춘다. GIF는 자르거나 늘리지 않고, 목업 원본 파일도 유지한다.
- 재생 끄기 버튼은 정지 이미지로 전환한다. 모션 감소 설정에서는 정지 이미지로 시작하고 사용자가 재생할 수 있다.

## 반응형과 스타일

- 기존 Pretendard와 공통 요약·섹션 제목·회고 컴포넌트를 사용한다. 본문은 다른 상세 페이지와 동일하게 행간 1.6, 기본 16px·75rem 이상 17px를 적용한다.
- 프로젝트 강조색 `#385dd9`, 옅은 배경 `#eef1f7`, 상황·결과 배경 `#f5f5f5`를 적용한다.
- 시안의 카드·태그와 개선 목표의 그라데이션은 이 프로젝트 시안에 한정한다.
- 75rem 이상: 40px 간격의 4열 중 우측 3열을 본문으로 사용한다. Figma의 좌측 태그/우측 콘텐츠 정렬을 유지한다.
- 48rem 미만: 전후 비교와 제작 순서 도식은 세로로 전환한다. 가이드·튜토리얼 6장은 DEEP-AI 편집·브랜드 페이지와 동일한 가로 스와이프와 6개 페이지 점을 사용한다. 다음 이미지 일부를 노출하고, 점 선택·좌우 방향키·이미지 확대를 지원한다. 48rem 이상에서는 기존의 큰 이미지 2장과 2열 튜토리얼 배치를 유지한다.
- 세부 기능 화면은 확대 다이얼로그를 제공한다. 모바일 확대 화면은 가로 스크롤로 내용을 확인하고, 닫기·Escape·배경 클릭으로 닫는다.
- 모바일 본문 설명–시각 자료 80px, 인접 섹션 160px 리듬을 적용한다.

## 검수

- 320·390·768·1440px 뷰포트에서 문서 가로 넘침이 없음을 확인했다.
- 실제 브라우저에서 모바일 노트북/GIF 비율, 데스크톱 전후 비교와 본문 정렬, 이미지 확대, Escape 닫기, GIF 재생 전환을 확인했다.
- GIF 19프레임의 크기와 각 프레임 재생 시간을 생성 스크립트에서 검증한다.
- ESLint, TypeScript 검사와 정적 내보내기 빌드를 완료했다.
- 실제 휴대폰에서 사용자와 줄바꿈·여백을 확인하는 최종 검토는 별도 진행한다.

- 제품 소개 버튼은 DEEP-NDT에서 추출한 공통 `ProjectProductLink`를 사용한다. 직각 테두리, 8px 화살표 간격, 15px/1.6 글자와 프로젝트 강조색 호버를 공유한다.
